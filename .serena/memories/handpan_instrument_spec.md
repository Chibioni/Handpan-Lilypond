# ハンドパン楽器仕様（概要）

詳細は `/Users/chibioni/Github/Handpan-Lilypond/HANDPAN_SPEC.md` を参照。

## 構造（上面から見た配置）

```
         [TF8]
   [TF7]        [TF6]
[TF5]    [Ding]    [TF4]
   [TF3]        [TF2]
         [TF1]       ← 手前（奏者側）
```

- Ding: 中央凸型、Dimple あり、楽器全体の最低音・ルートノート
- TF1（最低リング音）が手前、TF8（最高リング音）が奥
- 隣接する TF は音高が離れた交互配置（共鳴干渉を回避）

## 演奏
- 標準構え: TF1（最低リング音）を手前に向ける
- 非クロマティック楽器: 調律されたトーンフィールドの音のみ演奏可能

## このプロジェクトの記譜法（位置記譜法）
- 実音ではなく**物理的位置**を五線譜に対応
- Ding = B3（固定）、TF1 = D4、TF2 = E4 … TF8 = D5
- 実音・スケールが変わっても記譜位置は変わらない
- 変音記号は現行の Handpan.ily では未対応（既知の制限）
