# MIDI 処理 仕様書

MIDI ファイルの読み込み・テンポ処理・拍子処理・量子化の仕様。  
データ構造は `SPEC_data_structures.md` を参照。

---

## MIDI 読み込み仕様

対応フォーマット・velocity → アーティキュレーション変換・奏法マーカーノート・ハーモニクスの MIDI 記録方法については [README.md](README.md#入力-midi-の仕様) を参照。

### 読み込む MIDI イベント

| イベント | 処理 |
|----------|------|
| `note_on`（velocity > 0） | ノート開始として記録 |
| `note_on`（velocity = 0） | `note_off` と同等に扱う |
| `note_off` | ノート終了として記録 |
| `set_tempo` | テンポ更新（テンポチェンジに対応） |
| `time_signature` | 拍子更新（拍子チェンジに対応） |
| 上記以外 | 無視 |

ハーモニクスノートは MIDI 読み込み段階では通常の `note_on` / `note_off` として記録し `MidiNoteEvent` に変換する。ハーモニクスかどうかの判定は変換仕様（`SPEC_midi_to_score.md`）で行う。

### ノートオン重複の処理

同一 MIDI ノート番号が `note_off` 前に再度 `note_on` を受信した場合、
直前の `note_on` のティック位置を `tick_end` として確定し、新しい `note_on` を開始する。

## テンポ処理仕様

- デフォルトテンポ: 500,000 μs/拍（= 120 BPM）
- `set_tempo` イベントが存在する場合はその値を使用する
- テンポチェンジがある場合は、各ノートの `tick_start` 時点で有効なテンポを使用する
- `--tempo` オプション指定時は MIDI 内の全 `set_tempo` を無視し、指定 BPM を固定使用する

### ティック → 拍数の変換

```
beats = tick_duration / ticks_per_beat
```

`ticks_per_beat` は `MidiFile.ticks_per_beat` から取得する。

---

## 拍子処理仕様

- デフォルト拍子: 4/4
- `time_signature` イベントが存在する場合はその値を使用する
- 拍子チェンジがある場合は、各ノートの `tick_start` 時点で有効な拍子を使用する

### 小節長の計算

```
beats_per_bar = numerator * (4 / denominator)
```

例: 4/4 → 4.0 拍/小節、3/4 → 3.0 拍/小節、6/8 → 3.0 拍/小節

### 小節線の自動挿入

トークン列生成時に、各ノートの `tick_start` から小節境界を検出し、小節線トークン `\|` を自動挿入する。

- 各小節の先頭 tick を `bar_start_ticks` として管理する
- ノートの `tick_start` が次の小節境界に達したとき、そのノートの直前に `\|` を挿入する
- スキップされたノートは小節線の計算に影響しない

## 量子化仕様

### 対応音価

| 音価 | 拍数 | 記法文字列 |
|------|------|------------|
| 全音符 | 4.0 | `1` |
| 二重付点2分音符 | 3.5 | `2..` |
| 付点2分音符 | 3.0 | `2.` |
| 2分音符 | 2.0 | `2` |
| 二重付点4分音符 | 1.75 | `4..` |
| 付点4分音符 | 1.5 | `4.` |
| 4分音符 | 1.0 | `4` |
| 二重付点8分音符 | 0.875 | `8..` |
| 付点8分音符 | 0.75 | `8.` |
| 8分音符 | 0.5 | `8` |
| 付点16分音符 | 0.375 | `16.` |
| 16分音符 | 0.25 | `16` |
| 付点32分音符 | 0.1875 | `32.` |
| 32分音符 | 0.125 | `32` |

`--min-duration` で指定した音価より短い音符は量子化対象外（スキップ）とする。

### 量子化アルゴリズム

拍数と対応音価リストの差が最小の音価を選択する（最近傍量子化）。

```python
def quantize(beats: float, candidates: list[tuple[float, str]]) -> str | None:
    """
    candidates: [(拍数, 記法文字列), ...] を拍数昇順で渡す
    min_duration より短い場合は None を返す（スキップ対象）
    """
    return min(candidates, key=lambda c: abs(c[0] - beats))[1]
```
